A faster drop-in for makefun-site 1.0.0: a dependency-free static site generator in Node 22 stdlib only. `solve.js` answers every case exactly as makefun-site does — same front matter, template dialect, Markdown subset, slug rule and report, byte for byte — but scans with plain character tests instead of a regex per line and per character, escapes text in bulk spans, and caches the slugs and long dates a case repeats. `main.ts` reads every case from `/input/cases.json` and writes `/output/answers.json`.

## Run it

```sh
node main.ts
```
